# braindesmond5-boop.github.io

The short address for installing [B5 Code](https://github.com/braindesmond5-boop/b5code) on Windows. In PowerShell:

```powershell
irm braindesmond5-boop.github.io/b5 | iex
```

`b5/index.html` is one line that runs B5 Code's installer, `windows/install.ps1` in the b5code repo.
